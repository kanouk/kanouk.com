# Yohaku design system

Yohakuは、カノログと公開写真アーカイブに共通する表示設計です。白と黒を基調に、装飾を減らすこと自体ではなく、読む・探す・写真を見る行為が静かに続くことを目的にします。元WordPress／SmugMugの機能と可読性を下回らないことを最低条件とし、単なるテーマ再現ではなく、移行後のほうが整っている状態を公開条件にします。

## タイポグラフィ

- 日本語本文・見出し・UIはNoto Sans JPに統一する。配信weightはRegular 400とSemiBold 600の2種に絞り、本文と見出しの差をサイズだけでなくweightでも明確にする。中間UIの500指定はブラウザが近い配信weightへ解決し、不要な日本語font subset取得を増やさない。
- 本文は約16–18px、行高1.92、最大39rem。長文で現在位置を見失わず、1行が長くなりすぎない幅にする。
- 日本語見出しはプロポーショナル詰めを無効にし、字間0.005–0.01em、行高1.42–1.52。大きさだけで階層を作らず、ウェイトと前後余白を併用する。
- サイト名は600、1rem、字間0.045em。キャッチコピーは400、0.66rem、字間0.075emで、ロゴと説明の役割を分ける。
- 見出しは最大でも約34pxを通常上限とし、長い日本語タイトルを巨大な塊にしない。

## グリッドと余白

- 4 / 8px系の段階的な余白を使い、近接・区切り・章の切り替えを同じ値にしない。
- 記事の上部メタ、タイトル、カバー画像、本文は同じ主軸へ揃える。著者・タグ等の補助情報だけを左レール、目次・探索機能を右レールへ分ける。
- 68rem未満では右レール、48rem未満では左右レールを解除し、本文を一列にする。
- 罫線は境界がないと誤読する箇所だけに使う。画像直下、セクション見出し、画像なしカードに機械的な線を置かない。

## 画像

- トップと一覧のカバーは統一比率でトリミングし、カードのリズムを揃える。元画像そのものを見せる記事本文・写真詳細は縦横比を保持する。
- 寸法の小さい画像は本来の解像度を越えて拡大しない。余白が必要な場合は、サイト背景と区別できる静かなステージとして扱う。
- 画像がない記事にも同じ比率のYohakuプレースホルダーを置き、テキストだけのカードを別のレイアウトにしない。
- WordPress画像の指定幅、配置、キャプション、photo-frame／border／shadowの意味をPortable Textへ保持する。photo-frameは白い内縁、薄い境界、ごく弱い影で表現する。
- アルバムカバーと一覧はデザイン優先でcrop、写真詳細はcontain。写真上の前後移動、キーボード、swipe、全画面、共有、自動再生、download policyを維持する。

## 色と操作

- lightは白と#181a18付近、darkは#111211と#f2f3f2付近。青系accentはリンク、現在位置、意味のあるLucide iconに限定する。
- アルバム一覧はdesktop 3列、tablet 2列、mobile 1列とし、カード幅を30rem（480px）以内へ制限する。小さい原本を一覧都合で拡大せず、低解像度coverはhover zoomからも除外する。同じ4:3 crop契約の中で余白と密度を整える。
- 引用は`yohaku.quote`で本文、複数段落、箇条書き、inline mark、出典を一つの意味単位として保持する。本文と同じ文字サイズ・行間を使い、淡い面、accentの左線1本、控えめなQuote iconで本文との差を示す。
- 操作対象は原則44px相当の高さを確保し、hoverだけでなくkeyboard focusを明示する。
- motionは内容理解を助ける短い変化だけにし、`prefers-reduced-motion`を尊重する。

## 公開前の合格条件

1. 320 / 390 / 768 / 1024 / 1440pxで、タイトル、画像、本文、メタ情報の基準線と余白を実画面確認する。
2. featured imageあり／なし、横長／縦長／小解像度、長い日本語タイトル、photo-frame本文画像、Pochipp商品画像あり／なしを確認する。
3. すべての操作をkeyboardで実行でき、主要操作のtouch target、focus、dark mode、200%拡大で破綻しないことを確認する。
4. 元ブログ／SmugMugの代表ページと並べ、機能欠落、画像の過拡大、不要な余白・罫線、読みにくい字詰めがないことを確認する。

参考: [Apple Typography](https://developer.apple.com/design/human-interface-guidelines/typography)、[Apple Layout](https://developer.apple.com/design/human-interface-guidelines/layout)、[WCAG 2.2](https://www.w3.org/TR/WCAG22/)。数値をそのまま模倣せず、Web上の日本語長文と写真閲覧に合わせて適用します。
