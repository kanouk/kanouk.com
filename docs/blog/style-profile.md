# カノ文体の参照方法

## 最初に読む文体定義

`/Users/kanouk/Documents/Private/90_prompts/カノ文体.md`

2026-11-01に、本人からこの定義を使い、わかりやすさを維持して書き直すよう依頼された。以後のEmDash更新記事もこのファイルを全文読んでから書く。以前この場所にあった、公開記事3本から独自に推定したプロファイルは廃止した。

文体定義そのものはPrivate Vaultに置いたままにし、全文や私的な標本を公開リポジトリへ複製しない。参照できない場合は、推定した文体で代用して自動公開せず、確認できないことを報告する。

## 更新記事での使い方

- 文体定義の常体・独白・伝聞・短長の変化・控えめなセルフツッコミを、記事の内容に合わせて使う。口癖や冗談を定数のように挿入しない。
- 何が起きるかを具体的に説明し、読み手が変更を理解するための順序や条件を省かない。
- 公式から得た情報は伝聞として書き、このサイトで実際に確認したことと区別する。
- 本人が述べていない過去の経験・操作・失敗・私的な出来事を作らない。一般的な場面の例を本人の体験談へ変えない。
- 文体化のために新機能、保証、適用状況を加えない。事実確認の結果を推測へ変えない。
- `explain-before-shorten` で説明を整理してから、`yomiyasu` で意味・条件を照合する。一般的な校正規則で、本人が指定した文体のリズムやセルフツッコミを一律に消さない。
