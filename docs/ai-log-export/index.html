AI Data Export Guide

AIチャットの履歴を
書き出す方法

ChatGPT・Claude・Geminiに残っている会話や設定データを、手元のファイルとして保存するための手順です。

対象：パソコンのWeb版 所要時間：各5〜10分 更新：2026年8月9日
✓
書き出しても、元のチャットは削除されません。
準備が終わると、登録メールアドレスにダウンロード案内が届きます。
ChatGPT Claude Gemini
G

設定画面から書き出す

ChatGPT

ChatGPTのWeb版へログインして操作します。Free・Plus・Proの個人アカウントで利用できます。

  1. 画面左下のプロフィール画像を押し、設定を開きます。
  2. 左側のメニューからデータ コントロールを選びます。
  3. データをエクスポートするの右側にあるエクスポートするを押します。
  4. 確認画面が出たら、もう一度エクスポートを確定します。
メールが届いたら「Download data export」からZIPを保存します。案内が届くまで最大7日かかる場合があり、ダウンロードリンクは受信後24時間で期限切れになります。
C

設定画面から書き出す

Claude

ClaudeのWeb版またはデスクトップアプリから操作します。スマートフォンアプリからは書き出せません。

  1. 画面左下の自分のアイコンを押し、設定を開きます。
  2. 左側のメニューからプライバシーを選びます。
  3. 「あなたのデータ」にあるデータのエクスポートを押します。
  4. 確認画面の案内に沿って、書き出しを依頼します。
メールが届いたらClaudeへログインした状態でダウンロードします。リンクは受信後24時間で期限切れになります。切れた場合は、同じ手順でもう一度依頼できます。
✦

Google Takeoutから書き出す

Gemini

Geminiを使っているGoogleアカウントで、Google データ エクスポートを開きます。

!
会話ログとGemは、選ぶ項目が別です。画像の「Gemini」だけを選ぶと、主にGemの名前やカスタム指示が対象になります。過去のチャットを書き出すには、必ず「マイ アクティビティ」も選びます。
会話履歴

マイ アクティビティ 必須

「すべてのアクティビティ データが含まれます」を開き、いったん選択を解除して「Gemini Apps」だけを選びます。

Gemの設定

Gemini 必要なら

自分で作成したGemの名前やカスタム指示なども保存したい場合に選びます。

  1. Google Takeoutで、最初に選択をすべて解除します。
  2. マイ アクティビティにチェックを入れ、対象を「Gemini Apps」だけにします。
  3. Gemも保存する場合は、画像のようにGeminiにもチェックを入れます。
  4. ページ下部の次のステップを押します。
  5. 配信方法は「メールでダウンロードリンクを送信」、頻度は「1回エクスポート」、形式はZIPが簡単です。
  6. エクスポートを作成を押して完了です。
メールが届いたらGoogleから届く案内を開き、データをダウンロードします。作成には数時間〜数日かかる場合があります。メールで届くリンクは7日間有効です。
