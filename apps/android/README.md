# カノログ写真（Android）

写真サイトのアルバムを、スマホから作る・まとめて写真を追加する・編集する・公開するためのアプリ。管理画面の「写真を整理」と同じデータを同じ形で作るので、どちらからでも続きを作業できる。

## できること

- アルバム一覧（表紙・点数・撮影期間・下書き／未公開の変更）。右上の＋で新しいアルバムを作り、続けて写真を選ぶ。
- 写真を選ぶ画面は自前のギャラリー。日付ごとのまとまり、フォルダーでの絞り込み、「この日をすべて選択」、長押しして指でなぞるまとめ選択。アルバムにすでにある写真は「追加済み」になり選べない。
- アップロードは裏で続く（通知に進み具合）。アプリを閉じても止まらず、失敗した分だけ再試行できる。同じ写真（名前と大きさ、または内容のハッシュ）は省略する。
- **撮影日時と位置情報を残す。** ブラウザから送ると Android が位置情報を消すが、アプリは「写真の位置情報」の許可（ACCESS_MEDIA_LOCATION）を受けて元のファイルを送る。
- アルバムの写真は長押し＋なぞりでまとめて選び、非公開・表紙・削除（管理画面のゴミ箱へ）。
- 写真を開くと全画面。左右にスワイプ、ピンチ／ダブルタップで拡大。タイトルとキャプションの編集、非公開／再公開、表紙、地図、削除。
- 追加や編集は下書きになり、アルバムの「公開する／変更を公開」でまとめてサイトに出る（非公開の写真は出ない）。表紙のないアルバムには、最初に追加した写真が表紙として入る。

## ログイン

EmDash の OAuth デバイスフローを使う。アプリにコードが出るので、管理画面にログインしているブラウザで `https://blog.kanouk.com/_emdash/admin/device` を開いて承認する（スマホでもパソコンでもよい）。アプリはパスワードを扱わない。トークン（90日更新）はアプリ内にだけ保存し、メニューの「ログアウト」で消える。

## ビルドとインストール

必要なもの: JDK 17、Android SDK（platform 37、build-tools 36）、USB デバッグを有効にした端末。

```sh
cd apps/android
JAVA_HOME=/opt/homebrew/opt/openjdk@17 ./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

`local.properties` に `sdk.dir=<Android SDK のパス>` を置く（コミットしない）。

## 開発サーバーで試す

`apps/web` の開発サーバーを起動し、`adb reverse tcp:4321 tcp:4321` のうえで、ログイン画面の「接続先」を `http://localhost:4321` にする（平文 HTTP は localhost だけ許可）。
